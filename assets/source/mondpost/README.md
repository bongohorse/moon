## Integration notes

- Each image has an RGBA alpha channel and fully transparent pixels. Some images retain soft translucent edge halos; check compositing on the actual game background.
- Canvas dimensions, margins and component scales differ. Crop transparent padding and establish explicit pivots when preparing runtime sprites; preserve the originals here.
- Use the wheel sprite for both wheels. Driver and cargo box are separate chassis attachments. The suspension image is one static component; adapt its placement/animation to actual joint movement.
- Background layers are not certified seamless. Check transitions when repeating or arranging them.
- Add pedal labels using the GUI font. Pressed states can be produced through GUI styling.
- Ground details are decorative overlays. Render the driveable surface from the physical terrain data.
- The solar station is available artwork, not evidence of implemented charging gameplay.
- These files are not yet registered in the runtime atlas. Prepare appropriately sized runtime sprites and review their appearance before wiring them into the game.

`manifest.json` records original dimensions, byte sizes, SHA-256 hashes, alpha ranges and alpha bounds (left, top, right, bottom).
