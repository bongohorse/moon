# Development plan

## Phase 1: acceptance gate

1. Stable toolchain, repository rules, CI, Pages, Android artifact and Renovate.
2. Physical rover, terrain test track, touch/keyboard input and lifecycle safety.
3. Browser functional checks and explicit owner driving/visual acceptance.

Stop here. Subsequent work requires owner approval.

## Later phases (planning only)

- Refine art against accessible concept references and tune on physical Android hardware.
- Package delivery objectives and battery mechanics only after approved driving feel.
- Progression, audio, accessibility and persistence.
- Native mobile performance profiling, store preparation and iOS builds/signing.

No future milestone or gameplay implementation is started by this phase.
