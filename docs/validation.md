## Known setup diagnoses resolved

- Latest Bob needs Java 25; the machine initially had Java 21. Installed Java 25 from the official distribution and verified its published SHA-256.
- Current HTML5 platform is `wasm-web`, not the historical `js-web`. Explicitly select the single-thread wasm architecture so Pages does not require cross-origin isolation headers.
- Bob reserves `build/`; use `dist/` for distributable bundles.
- Current renderer constants live in the `graphics` namespace, including `BLEND_FACTOR_*`.
- Static slab collision shapes are sized explicitly with the documented `physics.set_shape` API, rather than relying on factory nonuniform collision scaling.
- Joint property updates reset omitted spring fields. Supply motor, spring and damping values together.
- Legacy joint setters scale motor torque, unlike initial creation; divide intended physical torque by the 0.01 physics scale when updating. Force messages also scale force, so the air force couple compensates explicitly. These version-specific choices must be reviewed with any engine/backend update.
- Very short automated key taps can occur between engine input frames; browser tests hold key presses for 80 ms.

## Limits

Headless browser checks use software rendering. They do not establish mobile GPU speed, native touch behavior, thermal stability or measured 60 FPS. No Android installation or iOS build/device test is claimed. Concept image fidelity remains pending because no source image files were accessible.

Native window listener handling is unchanged. The browser test dispatches a real browser blur event through the template bridge; this is an automated lifecycle check, not a physical mobile app-switch test.

## Browser functional checks

Automated Chromium checks passed for keyboard acceleration and braking, both-pedal brake priority, suspension movement, jump/landing, full default track completion (342 m), pause/body freezing, explicit resume, HTML5 focus-loss bridge, five repeated restarts, tuning changes staged/applied by restart, and emulated two-finger pedals with independent releases. Large desktop viewports can still increase canvas dimensions; further native/mobile GPU profiling remains necessary.

CDP `touchEnd` lists the released finger, not the remaining finger; the emulation test now uses the correct event semantics. Synthetic mouse events from touch do not replace the independent touch map.

## Box2D 3 migration

The owner requested an upgrade after phase-one completion and selected Defold's supported integrated Box2D 3.1.0 when the upstream/engine version distinction was explained. Defold 1.14.0 does not integrate upstream 3.1.1. The new app manifest has been accepted by the official native build service and produced a custom HTML5 engine.

The migration changes tires to the v3 shape friction API and creates explicitly spring-enabled wheel joints through documented b2d.joint handles. Defold's high-level v3 wheel creation disables the spring; using it unchanged would not satisfy the suspension requirement. Dedicated motor setters retain spring settings. The existing browser regression now requires the v3.1.0 engine log; full driving/lifecycle/touch checks and Android/production builds gate merging this change.

Cloud build diagnosis: Bob's Extender client ignores HTTPS_PROXY and failed direct network access. The loopback bridge now uses the platform HTTPS proxy and verifies TLS to the fixed official build service. No verification was disabled. Empty outdated example-manifest fields rejected by the service were removed.

Migration validation: all four checks passed on candidate 1cbf321 in GitHub run 38427440395. Local matching Playwright Headless Shell 156 then passed the complete regression: 342 m finish, 254 airborne fixed steps and six landings, moving suspension, air braking, repeated restarts, focus/pause/resume, tuning and simultaneous touch. The original local fixed-wall-time acceleration check was unstable with system Chromium and a full Chrome test binary under software rendering. Acceleration/braking now wait with bounded timeouts for the same motion thresholds; no thresholds or feature assertions were removed. Use Playwright's managed headless browser for matching local/CI results. Mobile performance and real-device feel remain open.
